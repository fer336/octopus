### Naming Conventions
- Python: `snake_case` for variables, functions, files
- React/TS: `camelCase` for variables/functions, `PascalCase` for components
- Database: `snake_case` for tables and columns
- Code: English identifiers, Spanish comments/UI/docs
- Git: Spanish conventional commits (`feat:`, `fix:`, `refactor:`, `docs:`, `style:`, `test:`)

### Architecture Patterns
- Clean/Hexagonal-inspired: `routers/` → `services/` → `models/`
- Async everywhere (FastAPI async, SQLAlchemy async)
- UUID primary keys with soft delete (`deleted_at`)
- FastAPI `Depends()` for dependency injection
- Frontend: Zustand for state, TanStack Query for server data
- No business logic in routers — only receive, validate, delegate
